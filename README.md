# 💰 Expense Tracker

### Track Your Expenses. Manage Your Money.

Expense Tracker is a web-based application designed to help users manage their daily income and expenses. It allows users to record transactions, monitor spending habits, and maintain better financial awareness through a simple and organized dashboard.

## 🌟 Features

- 🔐 User Authentication
- 💵 Add Income and Expenses
- 📝 Manage Transactions
- 📊 Expense Summary Dashboard
- 📅 Daily, Monthly, and Yearly Tracking
- 🗂️ Expense Categories
- 💳 Balance Calculation
- 📈 Expense Visualization
- 🎨 Clean and Responsive UI

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- Bootstrap

## 🚀 Installation & Setup

1. Clone the repository:

```bash
git clone https://github.com/yourusername/expense_tracker.git
```

2. Move the project folder to XAMPP `htdocs`.

3. Start Apache and MySQL from XAMPP Control Panel.

4. Open phpMyAdmin:

```text
http://localhost/phpmyadmin
```

5. Create the database and import the required SQL file, if provided.

6. Open the application in your browser:

```text
http://localhost/expense_tracker/
```
